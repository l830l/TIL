코딩 테스트 문제 중에는 프로그램 실행 시간이 특정 시간 미만이어야 한다는 조건이 있는 경우가 있다.
- 우리가 작성하는 코드의 실행 시간이 입력 데이터의 크기와 어떤 상관 관계가 있는지 파악해서 그 효율성을 계산한다.
- 이렇게 코드 혹은 알고리즘의 실행 시간과 데이터의 상관 관계를 시간 복잡도라고 한다.

# 2.1 시간 복잡도란? 
- 코드의 실행 시간이 어떤 요인으로 결정되는지 나타내는 시간과 입력 데이터의 함수 관계를 뜻한다.
## 2.1.1 빅오 표기법
- 알고리즘이 겪을 수 있는 최악의 경우에 걸리는 시간과 입력 간의 상관관계를 표기한다.
- 입력의 크기가 N이고, 이에 비례하는 시간이 걸린다면 O(N)으로 표기한다.
