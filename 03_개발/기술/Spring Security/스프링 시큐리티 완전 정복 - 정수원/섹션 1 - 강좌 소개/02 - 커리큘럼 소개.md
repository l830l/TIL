# 커리큘럼 소개
- 이번 강좌를 통해 학습해야 할 전체 section 과 주제에 대한 내용을 좀 보도록 한다.

## 전체 section과 주제
### 초기화 과정 이해
- 스크링 시큐리티 초기화 시 설정되는 빈, 구조, 흐름 등
- 스프링 시큐리티는 초기화 때 이루어지는 내용들을 알면 알수록 전체적인 스프링 시큐리티를 바라보는 관점이나 뷰가 더 커지고 더 넓어진다.
- 단, 초기화 과정이 복잡하고 양이 많기 때문에 다 다룰 수는 없지만 스프링 시큐리티를 우리가 잘 이해하기 위한 적정선에서 내용이 구성되어 있다. 
- 이 과정 자체가 스프링 시큐리티를 처음 접하는 분들은 좀 어려울 수 있다. 그 떄는 초기화 과정을 좀 건너 뛰고 그 다음 섹션부터 들어도 된다. 하지만 전체적인 내용을 다 들은 이후라도 초기화 과정은 꼭 듣길 권한다. 
### 인증 프로세스
- 폼 인증, 기본인증, 기억하기 인증 등
- 인증을 어떻게 할 수 있는지 에 대한 방법, API 설정 등의 Fundamental(기본적인, 근본적인)한 내용들을 좀 보도록 한다.
### 인증 아키텍처
- 인증 처리 구조, 원리, 객체 간 관계 등
- 인증 프로세스의 뒷단에서 흐르고 있는 구성이 된다.
- 인증 처리 구조가 어떻게 이루어지고 있는지 원리, 인증 프로세스에 사용되는 여러 클래스들과 그 객체 간의 관계가 어떤 식으로 연결되어지고 이루어지고 있는지 그런 아키텍처에 대한 내용들을 본다.
### 인증 상태 영속성
- 인증 상태 저장, 참조, 삭제 등의 유지 원리 등
- 인증을 하고 난 뒤에 인증을 계속 유지해야 한다. 그래서 인증 상태를 저장하거나 저장된 인증 상태를 어떻게 참조하고 삭제하는지 여러 가지 방법들에 대해 볼 수 있다.
### 세션 관리
- 세션 정보 관리, 동시 세션 제어, 세션 정책등
- 세션 정보를 관리할 수 있는 내용들 그 다음에 동시적으로 어떻게 세션을 제어하는지, 세션을 생성하거나 했을 때 어떤 식으로 정책을 펼칠 수 있는지 이런 세션 관리에 대한 내용을 본다.
- 스프링 시큐리티에서는 우리가 인증을 한 이후에 인증 상태를 유지하는 것도 디폴트는 세션을 통해 관리를 한다. 그렇기 때문에 세견 관리에 대한 내용도 중요하다.
### 예외 처리
- 인증, 인가 예외 처리 등
- 인증과 인가 두 가지 흐름 속에서 어떤 식으로 예외가 발생하고 또 그 발생된 예외를 어떤 식으로 처리할 수 있는지에 대한 내용들을 보도록 한다.
### 악용 보호
- CORS, CSRF, SameSite
- 악의적인 목적에 의해서 어떤 해커나 공격자가 소중한 자원들을 침투해서 가져가거나 세션을 변조하는 등의 일을 한다. 
- 스프링 시큐리티는 기본적으로 그런 악의적인 침입에 대해서 방어할 수 있는 기능들을 제공한다. 
### 인가 프로세스
- URL 기반, Method 기반 인가 처리 등
- 스프링 시큐리티에서는 권한을 우리가 설정하고 부여하고 관리할 수 있는 API 나 그런 클래스들을 제공한다. 
- 그 중에서 URL 기반, Method 기반 두 가지 기능을 통해서 인가 프로세스를 구현할 수 있다.
### 인가 아키텍처
- 인가 처리 구조, 원리, 객체 간 관계 등
- 인가 처리를 함에 있어서 그 뒷단에 흐르고 있는 인가 처리의 구조, 원리 객체 간 관계 이런 부분들을 인가 아키텍처적인 관점에서 살펴본다.
### 이벤트 처리
- 인증 이벤트, 인가 이벤트
- 어떤 식으로 이벤트가 발생하고 그 이벤트를 어떻게 우리가 캐치해서 사용할 수 있는지 그런 내용들을 보도록 한다.
### 통합하기
- 서블릿 통합, 스프링 MVC 통합
- 스프링 시큐리티에서 우리가 사용할 수 있는 인증이나 인가 그런 기능들을 서블릿이나 스프링 MVC 까지 확장해서 통합할 수 있는 그런 기능들을 스프링 시큐리티가 제공한다. 그래서 그런 방법들을 보도록 한다.
### 고급 설정
- 다중보안설정, Custom DSLs, 이중화 설정
### 실전프로젝트
- 회원 인증 시스템 / 회원 관리 시스템 구현
- 지금까지 배웠던 것을 하나에 프로젝트에 녹여서 진행한다.

# 개발 환경 & 필요사항
## 개발 환경
- JDK 17 이상
- Gradle
- Postgresql
- 인텔리제이(무료 버전도 가능) 또는 STS

##  선수지식
- Java(필수)
- Spring Boot(준필수)
- Spring MVC(준필수)
- Spring JPA(가급적 권장)
- Javascript
