# 서론
- 스프링 시큐리티 6점대 버전을 기준으로 제작되었다.
- 초반 버전과 6점대 버전이 매우 다르다. 따라서 5점대 버전의 지식으로 6버전을 사용하려고 하면 매우 많은 어려움이 따른다.
	- 5점대 버전에서 사용하던 많은 클래스들이 Deprecated 되거나 사용할 수 없는 API들, 그리고 클래스들이 없어지기도 했기 때문에 실질적으로 6점대 버전으로 Application 을 개발하려하면 5점대 버전을 알고 있던 사람들이 많은 어려움을 겪게 된다.
- 그래서 이번 강좌는 6.X 최신 버전으로 제작이 되었다. 또한 5.x 버전에서 다루지 못한 기능들을 포함해서 이번에 새롭게 추가되거나 병행된 그런 사항들을 집중해서 이번 강좌에 많은 공을 들여 제작을 하였다.

## Spring Security Milestone
- 스프링 시큐리티의 gitHub milestone 을 보면 현재 계속 버전 업을 하고 있다.
![[Pasted image 20260728234014.png]]
- 여기에 한번씩 들어와서 현재 시큐리티가 앞으로 버전업 때 어떤 기능을 추가하고 어떤 기능을 삭제하는지 내용들을 확인할 수 있다.
- Closed 되어 있는 것은 이미 개발이 완료되었다는 것이고 Open 은 진행 중이라는 뜻이다. 
- 그래서 Closed 들어가서 지금 현재 Spring Security 버전에 비해서 어떤 내용들이 앞으로 버전업이 되면 변경이 되거나 여러가지 내용들이 변화가 될 것인지에 대해 보면 된다.
- 예를 들어 7점대 버전을 보면 대부분 Remove 라고 되어있다. 이것은 Deprecated 된 항목들은 삭제하겠다라는 뜻이다. 이 부분들을 참고해서 우리가 코드를 작성해야 한다. 6점대 버전에서 이런 클래스나 API 를 사용할 수 있지만, 7점대 버전이 되면 다 삭제가 될 예정이기 때문이다. 그런 부분들도 milestone 에서 확인하는 것이 나쁘지 않을 것이다.
