###### 문제 25 트리 순회
- 문제
	- 저자권장 시간 40분 | 권장 시간 복잡도 O(N) | 출제 저자 출제
	- 이진 트리를 표현한 배열 `nodes`를 인자로 받습니다.
	- 예를 들어 `nodes`가 `[1, 2, 3, 4, 5, 6, 7]`이면 다음과 같은 트리를 표현한 것입니다.
		![[Pasted image 20260530230705.png]]
	- 해당 이진 트리에 대하여 전위 순회, 중위 순회, 후위 순회 결과를 반환하는 `solution()` 함수를 구현하세요
- 제약조건
	- 입력 노드값의 개수는 1개 이상 1,000개 이하이다.
	- 노드값은 정수형이며, 중복되지 않는다.
- 입출력의 예
	- \[1,2,3,4,5,6,7] > \["1245367", "4251637", "4526731"]
- 의사코드(배열로 풀어보기)
	1. 트리를 구축한다. 
		1. N 만큼 반복한다.
		2. 0번의 N\[0]는 arr\[1]로 둔다.
		3. N\[1]은 N\[0]의 왼쪽 자식이므로 2 * 1 = 2 즉, arr\[2] 에 둔다.
		4. N\[2]번은 N\[0]의 오른쪽 자식이므로 2 * 1 + 1 = 3. arr\[3]
		5. N\[3]번은 N\[1]의 왼쪽 자식이므로 arr\[2]의 왼쪽 자식이라서 2 * 2= 4. arr\[4]
		6. N\[4]번은 N\[1]의 오른쪽 자식이므로 2 * 2 + 1 = 5. arr\[5]
		7. N\[5]번은 3의 왼쪽 자식이므로 arr\[3]의 왼쪽 자식이라서 3 * 2  = 6. arr\[6]
		8. 즉, i 일 때 arr 의 인덱스는 i + 1
	2. 부모와 자식의 인덱스를 생각한다.
		1. 부모는 자식인덱스/2이고, 반대로 왼쪽 자식은 2N, 오른쪽 자식은 2N +1 임을 생각하며 푼다.
	3. 해당 인덱스를 바꿔서 전위 순회, 중위 순회, 후위 순회를 짠다. 방문한 것은 flag 를 1로 바꾸고 result 배열에 넣는다.
- 푼 코드 
``` java
import java.util.*;  
  
class Solution {  
    public String[] solution(int[] nums) {  
        // 트리를 구축한다.  
        int [] tree = new int[nums.length + 1];  
        int len = nums.length;  
        for(int i = 0; i < len; i++){  
            tree[i + 1]= nums[i];  
        }  
  
        return new String[]{  
                preOrder(tree, 1, len + 1), // 전위순회  
                inOrder(tree, 1, len + 1),  // 중위순회  
                postOrder(tree, 1, len + 1) // 후위순회  
        };  
    }  
  
    // 전위 순회  
    private String preOrder(int[] tree, int idx, int treeLen) {  
        StringBuilder sb = new StringBuilder();  
        sb.append(tree[idx]);  
        // 왼쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 < treeLen) {  
            sb.append(preOrder(tree, idx * 2, treeLen));  
        }  
        // 오른쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 + 1 < treeLen) {  
            sb.append(preOrder(tree, idx * 2 + 1, treeLen));  
        }  
        return sb.toString();  
    }  
  
    // 중위 순회  
    private String inOrder(int[] tree, int idx, int treeLen) {  
        StringBuilder sb = new StringBuilder();  
        // 왼쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 < treeLen) {  
            sb.append(inOrder(tree, idx * 2, treeLen));  
        }  
        sb.append(tree[idx]);  
        // 오른쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 + 1 < treeLen) {  
            sb.append(inOrder(tree, idx * 2 + 1, treeLen));  
        }  
        return sb.toString();  
    }  
      
    // 후위 순회  
    private String postOrder(int[] tree, int idx, int treeLen){  
        StringBuilder sb = new StringBuilder();  
        // 왼쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 < treeLen) {  
            sb.append(postOrder(tree, idx * 2, treeLen));  
        }  
        // 오른쪽 자식이 있으면 그쪽으로 이동하여 반복  
        if(idx * 2 + 1 < treeLen) {  
            sb.append(postOrder(tree, idx * 2 + 1, treeLen));  
        }  
        sb.append(tree[idx]);  
        return sb.toString();  
    }  
}
```

###### 문제 26 예상 대진표
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12985)
- 문제 분석
	- N : 참가자 수
	- 1-2, 3-4 끼리 게임 진행하여 이긴 사람끼리 다음 라운드 진출
	- 다시 번호를 N/2 번까지 배받음 
	- 이런 식으로 최종 한 명이 남을 때까지 진행됨.
	- 4번을 가진 참가자는 7번과 만나게 되기까지 몇번째 라운드에서 만나는가
	- 단 만나기 전까지 계속 이김
	- 단, 부전승 발생 안함
- 의사 코드
	1. 먼저, 무조건 배열에서 2개씩 짝짓는다.
	2. 둘이 마주치면 멈추고 몇번 싸웠는지 반환한다.
	3. 만약 두번째 또는 세번째 매개변수 숫자가 들어오면 해당을 선택한다. 
	4. 나머지는 인덱스가 홀수를 선택한다.
	5. 그리고 2/N으로 하여금 다시 반복하는데, 만약 N이 1이되면 멈춘다.
- 푼 코드
``` java
import java.util.*;

class Solution {
    private int answer = 0;

    public int solution(int n, int a, int b){
        int[] nums = new int[n];
        for(int i = 1; i <= n; i++){
            nums[i - 1] = i;
        }
        makeFightTable(nums, a, b);

        return answer;
    }

    private int[] makeFightTable(int[] nums, int a, int b){
        // 1. 먼저, 무조건 배열에서 2개씩 짝짓는다.
        List<List<Integer>> fightList = new ArrayList<>();
        ArrayList<Integer> newFightList = new ArrayList<>();
        int numsLen = nums.length;
        for(int i = 0; i < numsLen; i++){
            fightList.add(Arrays.asList(nums[i], nums[++i]));
        }

        for (List<Integer> twoFight : fightList) {
            int fightA = twoFight.get(0);
            int fightB = twoFight.get(1);

            // 2. 둘이 마주치면 라운드를 멈추고 몇번 싸웠는지 반환한다.
            if ((fightA == a && fightB == b) || (fightA == b && fightB == a)) {
                answer++;
                return null;
            }

            // 3. 만약 두번째 또는 세번째 매개변수 숫자가 들어오면 해당을 선택한다.
            // 4. 나머지는 인덱스가 홀수를 선택한다.
            if (fightA == a || fightB == a) {
                newFightList.add(a);
            } else if (fightA == b || fightB == b) {
                newFightList.add(b);
            } else {
                newFightList.add(fightA);
            }
        }
        answer++;

        // 5. 그리고 2/N으로 하여금 다시 반복하는데, 만약 N이 1이되면 멈춘다.
        return makeFightTable(newFightList.stream().mapToInt(i -> i).toArray(), a, b);
    }
}
```
- 정답과 해설
	- 다음 라운드의 번호 홀수 즉 왼쪽 자식이면 + 1 하면 짝수가 되어 나머지 없이 잘 나누어 떨어진다. 
	- 오른쪽 자식에게 +1 하면 홀수가 되어 2로 나누면 나머지는 버려지고 위와 똑같은 결과가 된다.
	- 두 참가자의 번호가 같을 때까지 계산을 반복한다. 
	- 다음 라운드에 받을 번호가 같다는 것은 두 참가자가 만났다는 의미이다
``` java
class Solution{
	public int solution(int n, int a, int b){
		int answer;
		
		for(answer = 0; a != b; answer++){
			a = (a + 1) / 2;
			b = (b + 1) / 2;
		}
		
		return answer;
	}
}
```
